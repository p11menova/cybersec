Настоящие скриншоты Actions пока не добавлены.

После успешного запуска:

1. Открыть run и убедиться, что все четыре jobs зелёные.
2. Скопировать постоянную ссылку вида `https://github.com/p11menova/cybersec/actions/runs/<run_id>` сюда.
3. Сделать скриншот общего результата и **Job summary** заданий Bandit и Snyk (или открыть их логи).
4. Сохранить изображения в `docs/screenshots/` и вставить в README ссылками Markdown.
5. Скачать Artifacts `sast-bandit`, `sca-pip-audit`, `sca-snyk`, `test-reports` при необходимости приложить полные отчёты.

Не включать в скриншоты токены, значения секретов и пользовательские пароли.
Незавершённый/пропущенный скан не является доказательством отсутствия уязвимостей.
